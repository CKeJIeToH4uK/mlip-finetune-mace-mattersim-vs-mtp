# Манифесты источников

CSV-файлы в этой папке фиксируют состав очищенного репозитория и тяжелые артефакты, которые намеренно не включены.

- `included_manifest.csv`: скопированные и сгенерированные артефакты очищенного репозитория.
- `excluded_heavy_manifest.csv`: исходные датасеты, чекпоинты, веса моделей, результаты сборки, бинарные файлы и другие тяжелые артефакты, намеренно не включенные физически.

## Каноническая схема

Текущие CSV-заголовки являются каноническими для очищенного репозитория.
