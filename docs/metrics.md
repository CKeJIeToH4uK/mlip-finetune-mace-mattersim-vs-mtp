# Метрики и единицы

- ошибки энергии измеряются в `meV/atom`;
- ошибки сил измеряются в `meV/Å`;
- основные метрики: `MAE` и `RMSE`.

Репозиторий не меняет единицы измерения, обозначения разбиений, алгоритмы агрегации или финальные численные значения. Проверенные таблицы для сверки чисел лежат в `results/verified_metrics/`.
